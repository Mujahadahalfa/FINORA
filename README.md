# FINORA (PWA)

Isi folder: index.html, manifest.json, sw.js, icons/.

## Pasang di GitHub Pages
1. Buat repository baru di GitHub, mis. `finora`.
2. Unggah SEMUA isi folder ini (bukan zip-nya) ke branch `main`.
3. Settings > Pages > Source: Deploy from a branch > `main` / `(root)` > Save.
4. Tunggu 1-2 menit, buka `https://USERNAME.github.io/finora/` di Chrome Android.
5. Buka Pengaturan > Install di Android (atau menu ⋮ > Instal aplikasi).

Data tersimpan di perangkat. Unduh backup secara rutin dari Pengaturan.
